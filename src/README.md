# src/ — Código Fuente NEXO

Esta carpeta contendrá el código fuente de la plataforma en la próxima fase de desarrollo.

## Stack Tecnológico Planificado

### Frontend
- **React Native** — App móvil iOS/Android (offline-first)
- **Next.js** — Dashboard web para clubes
- **Tailwind CSS** — Estilos

### Backend
- **Node.js / Express** — API REST
- **PostgreSQL** — Base de datos principal
- **Redis** — Caché de rankings y scores
- **AWS S3** — Almacenamiento de videos de evaluación

### IA / Scoring
- **Python** — Motor del NEXO Score™
- **Algoritmo propietario** — Score técnico, físico, táctico y psicológico
